#  NotebookLM: Introdução à Análise de Dados

## Sobre o projeto

Este projeto foi desenvolvido como parte de um desafio da DIO, com o objetivo de utilizar o NotebookLM como ferramenta de aprendizagem ativa.

Escolhi estudar análise de dados porque é uma área da tecnologia que desperta meu interesse e que pretendo conhecer melhor. Durante o projeto, utilizei fontes abertas, testei diferentes prompts e organizei os principais aprendizados em um miniguia.

## Objetivos de estudo

- Entender o que é análise de dados.
- Conhecer as principais etapas de uma análise.
- Identificar ferramentas utilizadas na área.
- Aprender conceitos básicos de forma acessível.
- Testar diferentes formas de fazer perguntas ao NotebookLM.
